Smart Contract-Driven Certificate Authentication System

A decentralized, tamper-proof system for verifying and managing digital certificates using Ethereum blockchain and smart contracts. Ensure authenticity and eliminate certificate fraud with our innovative solution.

System Modules

Our platform consists of two main modules designed for administrators and users to manage certificates efficiently.

Admin Module

  • Secure Login (Email & Password)
  • User Management Dashboard
  • Certificate Verification Status (Accept/Reject)
  • User Credential Management
  • System Logout

User Module

  • Registration (Roll No, Name, Dept, Email & Password)
  • Secure Login (Registration ID & Password)
  • Send Certificate Request to Admin
  • View Certificate Status (Accept/Reject)
  • Download Verified Certificates
  • System Logout
